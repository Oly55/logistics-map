# 물류센터 지도 (수도권 물류센터 DB · 거래사례)

구글 시트 **물류섹터_투자자/거래사례/파이프라인/DB**의 `수도권 물류센터 DB`, `최근 물류 거래사례` 탭을 카카오맵 위에 표시하는 페이지입니다.

- 페이지: https://oly55.github.io/logistics-map/
- 데이터: 독립 Apps Script 프로젝트 **"물류 지도 API"**(웹 앱)가 시트를 읽어, 비밀번호가 맞을 때만 JSON으로 전달합니다.
- 이 저장소에는 데이터·키·비밀번호가 없습니다. `config.js`에는 웹 앱 주소만 있습니다.

## 파일
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 틀(요약, 지도+표시 항목, 세부 내용, 목록, 최근 기사, 비밀번호 입력) |
| `app.js` | 데이터 로드, 필터, 원 표시, 박스 개요, 상세/목록, 기사 |
| `style.css` | 스타일 |
| `config.js` | Apps Script 웹 앱 URL |
| `geo/` | 행정구역 경계(시도·시군구·읍면동, 검색 시 경계 표시용). 통계청 행정동 경계를 정리한 [vuski/admdongkor](https://github.com/vuski/admdongkor) ver20261001을 단순화. `index.json` = [코드, 이름, 시군구코드, 시도코드, 범위], `sido.json`·`sgg_시도코드.json`·`emd_시도코드.json` = 코드별 [폴리곤[링[[경도,위도]…]]] |

## 운영
- 시트에 센터/거래를 추가하면 다음 접속 때 자동 반영됩니다. 새 주소 좌표는 접속 시 15건, 나머지는 매시간 트리거가 변환합니다.
- 좌표가 틀린 곳은 시트의 숨김 탭 `_좌표캐시`에서 위도·경도를 고치고 출처를 `manual`로 적으면 고정됩니다.
- 비밀번호 변경: Apps Script > 프로젝트 설정 > 스크립트 속성 `map_passcode` 값 수정(재배포 불필요).
- 기사: 구글 뉴스 검색(최근 30일, 물류센터 + 거래/개발/임대 키워드), 3시간 캐시.
- Apps Script 코드를 고친 뒤에는 배포 > 배포 관리 > 수정(연필) > 버전: 새 버전 > 배포 — 같은 URL이 유지됩니다.
